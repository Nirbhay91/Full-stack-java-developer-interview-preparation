# Deloitte DSA Interview Question Bank — 5 to 10 Years Experience

> **Purpose:** Revision-focused list of DSA/coding problems reported in Deloitte interview experiences and current interview-prep sources. Exact questions vary by role, team, geography, and interview round. This is a consolidated practice bank, not a guarantee of what will be asked.

## Arrays & Strings

1. Two Sum — find two elements whose sum equals a target.
2. Find the second largest element in an array.
3. Find the maximum and minimum element in an array.
4. Find the largest element in an array.
5. Find the missing number in an array.
6. Remove duplicate elements from an array.
7. Left-rotate an array by `k` positions.
8. Find all pairs with a target sum.
9. Sort an array containing only `0`, `1`, and `2`.
10. Find the majority element.
11. Maximum-sum rectangle/subarray-style problem.
12. Check whether a string is a palindrome.
13. Reverse a string.
14. Count vowels, consonants, and words in a string.
15. Find the first repeated character.
16. Select/find the longest string.
17. Simple regular-expression/string matching.
18. Find the longest substring satisfying a character-frequency condition.
19. Sorted character frequencies.
20. Parameterized divisibility labels.
21. Minimum deletions required to make a string non-palindromic.

## Linked List

22. Reverse a singly linked list.
23. Merge `k` sorted linked lists.
24. Common linked-list traversal/manipulation variants involving pointers.

## Searching & Sorting

25. Implement binary search on a sorted array.
26. Apply sorting/searching to solve pair, range, and selection problems efficiently.
27. Merge-sort-style problems and divide-and-conquer variants.

## Stack / Queue

28. Validate parentheses / balanced brackets.
29. Stack-based problems involving next/previous greater or smaller elements.
30. Queue/deque-based window and traversal problems.

## Trees & Graphs

31. Find the left view of a binary tree.
32. Binary-tree traversal problems (DFS/BFS).
33. Tree-based search/path problems.
34. Graph traversal using BFS/DFS.
35. Basic shortest-path/traversal variants.

## Dynamic Programming / Greedy

36. Climbing Stairs.
37. House Robber.
38. Minimum-cost optimization problems such as solar-rooftop/filter-installation style questions.
39. Greedy interval/selection problems.

## Two Pointers / Sliding Window

40. Container With Most Water.
41. Sliding-window substring/array problems.
42. Two-pointer pair/triplet problems.

## Math / Recursion

43. Check whether a number is prime.
44. Find factorial using recursion.
45. Reverse an integer.
46. Find the sum of digits of a number.
47. Mathematical/logical pattern or series problems.
48. Pascal's Triangle.

## Hashing / Heap

49. Frequency-counting problems using HashMap/HashSet.
50. Top-K / heap-based selection problems.
51. Merge `k` sorted structures using a heap.

## Advanced / Scenario-Based Coding

52. Pair elements subject to a target or parity condition.
53. Maximum rectangle / maximum-sum matrix problems.
54. Event/resource scheduling and optimization variants.
55. Problems requiring optimization from brute force to `O(n log n)` or `O(n)`.

# Interview Coding Method

For every DSA problem, answer in this order:

**1. Clarify input/output**  
**2. Give brute-force idea**  
**3. Identify better pattern/data structure**  
**4. Explain algorithm**  
**5. Discuss edge cases**  
**6. Write clean Java code**  
**7. State time and space complexity**  
**8. Dry-run with sample**
